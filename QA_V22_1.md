# Mimi Muscu V22.1 — Hotfix GitHub Pages

## Bug critique corrigé

`js/core/data.js` faisait :

```js
fetch("../../data/exercises.json")
```

Un `fetch()` relatif est résolu par rapport à l'URL du document, pas au fichier module.
Sur GitHub Pages, la page est :

`/Mimimuscu/`

Le navigateur essayait donc de charger les JSON hors du dossier attendu.
Les imports top-level de `data.js` échouaient et `js/app.js` n'était jamais initialisé.

Correction :

```js
const url = new URL(path, import.meta.url);
fetch(url)
```

Le chemin est désormais calculé depuis :

`/Mimimuscu/js/core/data.js`

et résout correctement :

`/Mimimuscu/data/*.json`

## Sécurité ajoutée

`index.html` charge désormais `app.js` dynamiquement avec un `.catch()`.
Une future erreur de boot affiche un message visible au lieu de laisser une interface statique avec des boutons morts.
