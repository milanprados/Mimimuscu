# Mimi Muscu V24 — Local Visual Pack

- 100 exercices
- 3 assets locaux par exercice : start.webp / end.webp / thumb.webp
- 300 fichiers WebP
- poids total du pack : 2.50 MiB
- aucune illustration d'exercice n'est requise depuis Internet au runtime
- dictionnaire utilise thumb.webp
- séance utilise start/end
- esthétique homogénéisée : monochrome anatomique + accents rouge/orange
- service worker : mimi-muscu-v24

Note : cette première passe utilise les poses du dataset public-domain existant et une stylisation locale cohérente.
