# Mimi Muscu V22.2 — Runtime fix

## Deuxième bug critique trouvé

V22 a migré `programs.json` de :

```js
template.ids
```

vers un format générique :

```json
{
  "blocks": [
    {
      "type": "circuit",
      "items": ["pushups", "squat"]
    }
  ]
}
```

Mais `dashboard.js` et `sessions.js` utilisaient encore `template.ids`.

Résultat au démarrage :

`TypeError: Cannot read properties of undefined (reading 'map')`

La V22.2 fournit désormais une couche de compatibilité :
`workoutTemplate()` compile toujours les blocks et expose aussi `ids[]`.

## Sécurité
- dashboard protégé si ids est invalide
- planner protégé si ids est invalide
- nouveau test runtime spécifique
- cache PWA bumpé en v22.2
- import app.js cache-busté avec `?v=22.2`
