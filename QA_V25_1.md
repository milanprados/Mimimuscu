# Mimi Muscu V25.1 — SVG path hotfix

## Bug trouvé
V25 renvoyait dans `<img src>` un chemin comme :
`../../../assets/svg_exercises/Pushups/start.svg`

Dans un élément HTML `<img>`, ce chemin est résolu depuis la page :
`https://milanprados.github.io/Mimimuscu/`

Ce qui donnait à tort :
`https://milanprados.github.io/assets/...`

## Correction
Les URLs sont désormais calculées par :
`new URL(path, import.meta.url).href`

Depuis le module :
`/Mimimuscu/js/v25_1/core/data.js`

La même image résout donc vers :
`/Mimimuscu/assets/svg_exercises/Pushups/start.svg`
